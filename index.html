How to Read This Calendar
Four separate streams – one consistent regional cadence

This calendar repeats the same 9-week regional structure every quarter. Fire prospects and Backflow prospects run in parallel with separate themes. Webinars are only used as the core campaign asset for the Report Review upsell motion for existing Fire customers.

Fire Prospects – 50 states in 9 weeks (5–6 states weekly)
Backflow Prospects – same regional schedule, separate backflow themes
Upsell (Fire Customers) – bi-monthly by region (Fire Extinguishers ↔ Report Review)
Drips – Cold, Warm, High Intent based on behavior
Newsletter – Quarterly to Fire + Backflow accounts
